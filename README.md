## 👀 Como ver

- **No computador:** dê um duplo clique em `index.html` (abre no navegador).
- **No celular:** publique com uma das opções abaixo e acesse pelo link.

## 🚀 Como publicar de graça (GitHub Pages)

1. No GitHub, abra o repositório → **Settings** → **Pages**.
2. Em *Build and deployment*, escolha **Deploy from a branch**.
3. Selecione a branch `main` (ou a que estiver publicada) e a pasta `/root`. Salve.
4. Em alguns minutos o site fica no ar em `https://<seu-usuario>.github.io/<repositorio>/`.
