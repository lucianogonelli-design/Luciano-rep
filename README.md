## 🚀 Como publicar de graça (GitHub Pages)

Como o site está na pasta `bazar/`, a forma mais simples é:

1. No GitHub, abra o repositório → **Settings** → **Pages**.
2. Em *Build and deployment*, use **GitHub Actions** (workflow "Static HTML") **ou**
   mova/relacione a pasta para `/docs` — o Pages clássico publica a partir de `/` ou `/docs`.
3. Em poucos minutos o site fica no ar em `https://<seu-usuario>.github.io/<repositorio>/`.

> Dica: se preferir o modo clássico, é só renomear a pasta `bazar` para `docs`
> e escolher a pasta `/docs` nas configurações do Pages.
